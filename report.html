Introduction:

My website is a news website for the game, Paladins. It goes beyond the regular game announcements of new events and patches. It tells the story of the community and the big youtubers and content creators who are not the game developers. Whenever there's drama between players, or whenever a new meta is discovered, this news website will have that information. Game developers might have designed the game, but they don't know how the community wants to use it or they often cannot foresee what the balance of the game will be. This website will also have information on all the champions and which champions perform well and any guides you might need all in one place.

Inspiration:

  • 1. The paladins guru website which keeps track of all the players and their stats. https://paladins.guru/
  • 2. The youtuber JuiceHead who regularly uploads news videos for the game Cyberpunk 2077 which also includes community drama and exploits that players find
  • 3. The paladins wiki website which contains all the information for the game regarding lore and patch notes https://paladins.fandom.com/wiki/Paladins_Wiki.

    • Accessibility:

  • 1. I have added the ability to change the website's font into a more readable font through an accessibility button visible on every page
  • 2. I have added the ability to increase the font size of most text elements so they are more easily readable using a similar accessibility button
  • 3. I have given every image tag on the website a meaningful alt attribute

    • Usability:

  • 1. I have added hover effects to many clickable items to help the user tell what is clickable and what is not.
  • 2. I have added a side menu on every page with some having anchor links for easy navigation on some of the longer pages
  • 3. I have added font altering buttons to make the text far easier to read should the user choose to do so

    • Learning:

    • 1. I had to learn how to create a rotating banner. I achieved that by watching a youtube video made by Dani Krossing whose code I adapted to fit into my website.
    • 2. I had to learn how to create a dropdown menu. I achieved that from W3Schools
    • 3. I had to learn how to offset anchor links. I achieved that through experimentation.

    Evaluation I:

    I think the navigation was successful since I added anchor links on some longer pages for easy navigation. I also think the responsiveness was successful As the site smoothly transitions between displays.

    Evaluation II:

    I think the overall style and aesthetic could be improved because it does not look truly professional. The banner could also use improvement because its operation is not completely smooth
